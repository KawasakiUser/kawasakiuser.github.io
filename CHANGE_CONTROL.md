# Change control
This delivery is limited to Owner decisions 01A and 02A. Any change to repository identity, production Pages, A23, formal page templates, real personal content, logo, footer contacts, MDX/math execution, or release behavior requires PCS routing and new explicit authorization.
Implementation choices are Astro 5.18.2, Node/npm engine contract, base /, JSON glob loader, node --import tsx --test, and no deployment workflow. These choices are reversible within the foundation and do not freeze future visual or editorial decisions.
